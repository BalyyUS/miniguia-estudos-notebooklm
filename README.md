A ideia inicial foi utilizar a base do projeto sobre o "[Elon musk e a criação do ChatGPT](https://notebook.google.com/notebook/8f112b2d-11cd-440e-9921-35a464bd705e)", porém ao finalizar e adicionar o projeto ao Readme, percebi que meu conhecimento sobre git e ao mesmo era quase nulo, com isso cogitei em refazer o projeto e criar um novo notebook, inclusive para usos futuros de codigo e tals. Importei algumas fontes diretamente do *Google* sobre o github e como utilizar e utilitei o proprio "pesquisar com ia" do *NotebookLM* para me dar algumas fontes especificas sobre comandos git e sobre o readme.
